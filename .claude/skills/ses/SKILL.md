ses スキル
セッションの引き継ぎとリセットを行うスキルです。
コンテキスト使用量を確認し、必要に応じて引き継ぎを作成してリセットします。
使い方
/ses と入力して呼び出してください。

スキルの手順
以下の手順を順番に実行してください。
ステップ1：コンテキスト使用量を確認する
/context を実行して、現在のコンテキスト使用量を確認してください。

25%未満：まだ余裕があります。このスキルを終了して作業を続けてください。
25〜30%以上：リセットを推奨します。ステップ2に進んでください。


ステップ2：引き継ぎ内容を作成する
次のセッションがスムーズに始められるよう、以下の項目を含む引き継ぎ内容を日本語で作成してください。
引き継ぎに含める内容：

目的：このセッションで作っているもの・やっていることを1〜2文で説明する
完了済みの作業：すでに終わっていること（箇条書き）
現在地：今どのステップにいるか
次にやること：次のセッションで最初に行う作業
重要な決定事項：技術選定・設計の判断など、引き継いでおくべき内容
ファイル・フォルダ構成：作業フォルダのパスと主要ファイルの一覧（該当する場合）

作成した引き継ぎ内容を、次のコマンドでクリップボードにコピーしてください。

Mac の場合：pbcopy
Windows の場合：PowerShellの `Set-Clipboard` コマンドレットを使うこと。
  - `clip` コマンドはPowerShellのパイプ経由だと日本語が文字化けするため使用しないこと。
  - 引き継ぎ内容を一時ファイルに書き出した上で、`Get-Content -Raw -Encoding UTF8 <path> | Set-Clipboard` を実行する。
  - 完了後、一時ファイルは削除する。


ステップ3：セッションをリセットする
引き継ぎ内容がコピーできたことを確認したら、/clear を実行してセッションをリセットしてください。

ステップ4（ユーザーが手動で行う）：引き継ぎを貼り付ける
/clear を実行するとこのスキルも終了します。
リセット後、クリップボードにコピーした引き継ぎ内容をご自身で貼り付けて送信してください。
Claude Code が内容を理解し、続きから作業を再開します。

メモ

コンテキストが溜まるほど判断の精度が落ちます。こまめなリセットが品質を保つコツです。
/clear の代わりに /compact を使うと会話を要約して容量を節約できますが、再開まで時間がかかります。スピード重視なら /clear ＋引き継ぎ貼り付けの方が速いです。
よく使うフレーズは辞書登録しておくと便利です（例：「つぎ」→ 引き継ぎ作成プロンプト全文）。
